# Negative NCI is not a common-equity asset

A negative reported noncontrolling-interest balance does not automatically add
value to common shareholders. Preserve it as a source diagnostic and deduct only
the separately supported positive outside-owner claim. If a formerly nonpositive
component becomes positive, fail closed and reclassify it instead of silently
changing the bridge.

Recall when: an issuer reports redeemable NCI together with negative
nonredeemable NCI or minority interest.
