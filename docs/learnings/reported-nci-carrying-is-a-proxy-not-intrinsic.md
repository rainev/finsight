---
name: reported-nci-carrying-is-a-proxy-not-intrinsic
description: Use current NCI carrying once as a conservative common-equity bridge proxy only when consolidated enterprise cash includes outside ownership.
metadata: { type: gotcha }
---
WG33 MCK establishes a bounded ownership treatment: consolidated enterprise FCFF
includes controlled subsidiaries, while common shareholders do not own ordinary/
redeemable NCI. Current reported carrying may therefore serve once as an
accounting proxy for the ownership claim when current total/aliases/rollforward
reconcile and reliability stays Low.

**Why:** Calling book carrying intrinsic value is too strong, but refusing any
ownership bridge leaves consolidated enterprise cash attributable to common.
Adding floors, transaction values, remeasurement movements, proceeds or parent
dilution on top of ending carrying double-counts the same economics.

**How to apply:** label the basis `reported current carrying proxy`, not contract
intrinsic/redemption value. Lock same-period issuer/consolidation/source scope;
count ordinary and redeemable stocks once; keep flows/aliases/floors/event values
diagnostic; choose either a source-supported cash claim or conversion dilution,
never both. Missing executed terms block instrument-specific outcomes, not the
narrow ownership proxy. If enterprise cash is parent-attributable instead, or a
conversion/settlement changes the stock, review rather than reuse this rule.
