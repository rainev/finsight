Alpha Spread publicly describes characteristic-based model selection, historical/industry/analyst
inputs, and WACC-versus-cost-of-equity consistency, while explicitly calling its algorithm
proprietary. GuruFocus publicly requires the selected EPS/FCF input to use the matching growth rate
and warns that low predictability can make fair value volatile.

**Why:** A competitor displaying a number proves only that its product accepts a fallback; it does
not prove FinSight has the source facts needed to replay that number at the controlled cutoff.

**How to detect / apply:** Reuse public concepts—model suitability, matched flow/growth, scenarios,
historical normalization, predictability warnings—and cite the public methodology. Never import a
displayed value, reverse-engineer a proprietary algorithm, or let a competitor result clear a
FinSight source-safety gate. References:
`https://kb.alphaspread.com/hc/en-us/articles/18217888896017-What-is-DCF-Value` and
`https://static.gurufocus.com/download/GuruFocus%20User%20Manual%20DCF%202022.pdf`.
