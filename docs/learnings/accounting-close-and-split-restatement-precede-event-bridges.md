---
name: accounting-close-and-split-restatement-precede-event-bridges
description: A calendar reporting date can follow an event that occurred after the actual books closed, while shares are already retroactively split-adjusted.
metadata: { type: gotcha }
---
HON's June30-labelled quarter closes June27. The June29 Aerospace distribution
is therefore a subsequent fiscal event. The filing explicitly retains Aerospace
assets, liabilities and operations while retrospectively adjusting all shares
for the reverse split. Comparing the event only to the printed quarter-end date
or multiplying the reported share denominator by the split again is wrong.

Check the basis-of-presentation accounting calendar, explicit financial scope,
and retrospective per-share statement before deciding whether an event is in
the balances. A related carve-out statement with allocated corporate costs and
central cash pooling also requires eliminations and continuing-cost analysis
before subtraction yields a continuing-parent FCFF.
