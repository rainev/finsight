only if positive ordinary NCI reconciles to consolidated-minus-parent equity
and the NCI equity member. INTC's named consolidated subsidiaries must reconcile

event stack from this ordinary-only mechanism, without dropping them from the
required universe.

an exact annual schedule. INTC's approved foundry margins are explicit governed
assumptions, not the history median. Preserve those independent source/model
gaps and all historical deductions; no numeric successor until they are bound.
Reuse NCI equity reconciliation, commitment selection and fail-closed compiler
machinery; no source amount, accession or date in the rule tables.

Acceptance: JBL representative and INTC difficult subset case, real cached
filing proof, frozen two-worker flow, focused regression, independent economic
challenge and isolated API path. A blocked result is not a successful refresh,
an unavailable conversion or a completed issuer implementation.
