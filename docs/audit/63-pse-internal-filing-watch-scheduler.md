# Audit 63 — PSE internal filing-watch and stage-only scheduler

**Status: internal pilot implementation verified, 2026-09-26; user confirmation pending. No background job installed or left running, no external issuer request made, no approval or activation.** The user authorized one internal filing-watch and staged-refresh scheduler while keeping RLC on hold and the active catalog unchanged.

## Implemented boundary

- [One local tick/loop CLI](../../scripts/run_pse_intrinsic_refresh_watch.py) calls [refresh_watch.py](../../backend/app/pse_valuation/refresh_watch.py). A tick reads a versioned [pilot source registry](../../backend/app/pse_valuation/config/internal_filing_watch.json) and a local inbox of pinned reviewed bundles. `--watch` repeats the same tick in one local process; no OS/Cloud Scheduler job is installed.
- All AP/BPI/RCR/RLC automated-metadata-access flags are **false**. The registry does not claim source rights for public-site polling. A disabled source causes **no network request**. If later cleared through a recorded source-specific decision, the watcher can baseline an issuer HTML index and flag newly linked same-host PDFs as `needs_fact_and_rights_review`; it does **not** download or parse PDFs or use PSE EDGE. A changed index without a new link is flagged for review. Same-URL PDF changes without an index change are not currently detectable.
- Reviewed local bundles are staged once via the existing four-model internal runner. Repeated identical bundles are skipped, candidate construction happens in an isolated temporary directory before being moved into the stage root, and failures leave the active pointer untouched. The scheduler rejects any bundle that attempts to mark **RLC ready**; RCR changes preserve and flag RLC as a parent dependency. No current-price feed, Postgres/MinIO capture, auto-approval, or activation is added.

## Honest remaining work

This is a working **internal stage-only scheduler**, not a complete unattended filing-to-valuation service. The issuer index polling path was tested with controlled HTML, not enabled on live issuer sites because automated access rights are unrecorded. AP/BPI index paths are not configured. The job does not transform an arbitrary PDF into accounting-reviewed facts; humans still review extraction, ownership, capital claims and material assumptions and place a pinned bundle in the local inbox. Original-byte capture in MinIO, durable Postgres lineage, handling silent same-URL PDF replacements, source rights, production scheduling and a complete four-route pilot remain separate work. RLC's owner-level consolidated property bridge remains missing. Do not mark Phase C or an issuer valuation approved from this implementation alone.
